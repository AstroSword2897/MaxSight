# Productization Docs

Use this folder to drive simulation-to-product execution for MaxSight glasses.

## Document order
1. `01_product_scope_and_claims.md` - product boundaries, intended use, claims/non-claims.
2. `02_safety_first_release_gates.md` - mandatory V1 safety gates and thresholds.
3. `03_pipeline_declutter_map.md` - canonical command surface and script consolidation.
4. `04_runtime_boundary_spec.md` - critical vs secondary runtime contract and degraded modes.
5. `05_pilot_validation_protocol.md` - real-world pilot scenarios, KPIs, and review loop.

## Recommended reading sequence
- Product + safety owners: 01 -> 02 -> 05
- Platform/ML owners: 02 -> 03 -> 04
- Release managers: 02 -> 03 -> 05
