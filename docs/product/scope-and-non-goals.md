# Scope and non-goals (V1)

**In scope:** iOS app for low-vision adults; Stage A local hazard perception (offline); Stage B cloud contextual help (text and structured data only until DR-201 is decided); FVP preferences; accessible speech and haptic output.

**Non-goals:** complete-blindness support; per-condition (13-condition) models; Android (after the iOS V1); IMU, LiDAR or any sensor beyond camera and microphone; navigation routing; persistent environmental memory; sending images to the cloud (pending DR-201).
