# User capabilities (committed V1 list)

Committed capabilities only; see the capability matrix in `docs/architecture/v1/04-stage-b-specification.md` (D4.0).

1. Hazard alerts for the supported object classes, by speech and haptics, offline.
2. Read visible text aloud (on-device OCR).
3. Interpret read text and answer questions about detected objects (cloud, derived text only).
4. Find a requested object among the detector classes, with direction.
5. Short scene summary limited to detected classes.
