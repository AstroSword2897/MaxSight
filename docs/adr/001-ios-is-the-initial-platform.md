# ADR-001: iOS is the initial platform

- **Register ID:** DR-001
- **Status:** Confirmed
- **Source:** Directive §1

## Context / rationale
Native camera, Core ML, accessibility

## Alternatives considered
Android first; cross-platform

## Decision
iOS is the initial platform

## Consequences
The Swift app is the V1 product; the Python pipeline is reference and evaluation tooling only

## Dependencies
DR-206 device matrix

## Validation required
iOS device tests (D8)
