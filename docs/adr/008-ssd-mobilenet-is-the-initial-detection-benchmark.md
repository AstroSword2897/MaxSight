# ADR-008: SSD-MobileNet is the initial detection benchmark

- **Register ID:** DR-011
- **Status:** Confirmed
- **Source:** Q22, Q79

## Context / rationale
~3× faster than ResNet50+FPN in Google benchmarks; latency matters

## Alternatives considered

## Decision
SSD-MobileNet is the initial detection benchmark

## Consequences
First trained model
