We are training EVERY condition: 14 separate runs (one per vision condition),
each with its own checkpoint folder. Batch 16, T5, GradNorm, 20 epochs.

Everything we set up: T5 fixes, 14 vision conditions, warning recognition,
GradNorm, EMA, checkpoints on Drive. No --use-ema or --use-mixed-precision
(those flags don't exist; EMA is on by default, FP32 only).

REQUIRED: Put maxsight_train.json and maxsight_val.json in:
  /content/drive/MyDrive/MaxSight_Training/cleaned_splits/
Create them with: python scripts/gather_training_data.py --coco-dir <path> --output-dir <path>/cleaned_splits
Or use your own train/val JSON paths and set TRAIN_ANN / VAL_ANN in Cell 3.

HOW LONG: 14 models × 20 epochs each. Depends on train set size and GPU (see TIME_ESTIMATES.md).
  • ~2k train samples:  Colab T4 ~5–8 h total (faster cell) or ~10–14 h (standard); A100 ~2–3 h.
  • ~10k train samples: T4 ~1–2 days (use resume); A100 ~8–14 h.
  • Check first log line "Train samples: N" to see which row applies. Colab free often stops ~12 h — use --resume next run.

# Trains one model per vision condition; each saves to its own folder on Drive.
# Ensure we're in the repo (required if you didn't run Cell 1, or run training in another notebook).
import os
REPO = "/content/2026-Prototype"
os.chdir(REPO)
CONDITIONS = [
    "glaucoma", "amd", "cataracts", "color_blindness",
    "diabetic_retinopathy", "retinitis_pigmentosa", "cvi",
    "amblyopia", "strabismus",
    "refractive_errors", "myopia", "hyperopia", "astigmatism", "presbyopia"
]
DATA = "/content/drive/MyDrive/MaxSight_Training"
BASE_CKPT = "/content/drive/MyDrive/MaxSight"
# Annotation JSONs (required: create with gather_training_data.py or put maxsight_train.json + maxsight_val.json here)
TRAIN_ANN = f"{DATA}/cleaned_splits/maxsight_train.json"
VAL_ANN = f"{DATA}/cleaned_splits/maxsight_val.json"

for cond in CONDITIONS:
    ckpt_dir = f"{BASE_CKPT}/checkpoints_{cond}"
    print(f"\n{'='*60}\nTraining condition: {cond} -> {ckpt_dir}\n{'='*60}\n")
    !python {REPO}/scripts/train_maxsight.py \
        --data-dir {DATA} \
        --image-dir {DATA} \
        --train-annotation {TRAIN_ANN} \
        --val-annotation {VAL_ANN} \
        --batch-size 16 \
        --epochs 20 \
        --num-workers 2 \
        --grad-accumulation-steps 2 \
        --use-gradnorm \
        --condition-mode {cond} \
        --checkpoint-dir {ckpt_dir} \
        --checkpoint-interval 5 \
        --early-stopping-patience 10 \
        --device cuda \
        --seed 42
